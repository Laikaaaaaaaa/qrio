Thông tin vé

Chọn cách hệ thống xác nhận giao dịch. Khuyến nghị dùng API ngân hàng để tự động xác nhận nhanh chóng.

Lấy API Key từ trang quản lý ngân hàng của bạn hoặc liên hệ ngân hàng để được cấp.

Xem hướng dẫn tạo WebHook SePay.

Check thủ công: Khách hàng sẽ upload ảnh xác nhận chuyển khoản. Bạn cần vào trang Quản lý đơn hàng để duyệt thủ công.

Hướng dẫn sử dụng

  1. Điền thông tin vé và ngân hàng nhận tiền
  2. Nhấn "Tạo mã QR" để tạo mã bán vé
  3. Tải mã QR về và in ra hoặc hiển thị tại quầy
  4. Khách hàng quét mã → Nhập thông tin → Thanh toán
  5. Hệ thống tự động tạo vé điện tử cho khách
  6. Vào trang "Quét vé" để kiểm tra vé của khách
